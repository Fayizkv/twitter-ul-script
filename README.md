# SIO India Campaign - Tweet Generator

A simple, beautiful web tool to transform campaign text into ready-to-post Twitter links.

## 🚀 Features
- **Automatic Splitting**: Splits long text into multiple posts using numbered lists (1., 2., etc.).
- **One-Click Tweet**: Generates Twitter intent links that open the Twitter compose box with pre-filled text.
- **Copy All**: Quickly copy all generated links for sharing.
- **Dark Mode UI**: A premium, modern design with glassmorphism effects.
- **Auto-Load**: Automatically loads content from `text.txt` if available.

## 🛠️ How to Use
1. **Host it**: Upload `index.html`, `styles.css`, `app.js`, and `text.txt` to any static hosting service (GitHub Pages, Vercel, Netlify, etc.).
2. **Local Use**: Just open `index.html` in any modern web browser.
3. **Paste Text**: Paste your campaign text in the box. The format should be:
   ```
   1. First tweet content
   2. Second tweet content
   ```
4. **Generate**: Click "Generate Links" to see the list of Tweet buttons.

## 📁 File Structure
- `index.html`: Main layout and structure.
- `styles.css`: Visual styling and animations.
- `app.js`: Logic for processing text and generating links.
- `text.txt`: Default campaign content (optional).
